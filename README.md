# RevAI

Python-прототип чат-бота с хранением истории диалогов в SQLite.

## Возможности
- Обработка диалогов через модель ИИ
- Локальное хранение истории чата

## Структура
- RevAI.py и RevAI/ — приложение
- data/database/ — локальная база данных
- requirements.txt — Python-зависимости

## Запуск
Создайте виртуальное окружение, установите зависимости и запустите главный сценарий:
1. python -m venv .venv
2. активируйте окружение
3. pip install -r requirements.txt
4. python RevAI.py

## Безопасность
Не храните историю чатов и ключи API в публичном репозитории. В репозитории есть файл базы данных: проверьте его содержимое и историю Git перед публикацией.
